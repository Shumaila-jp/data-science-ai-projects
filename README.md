## Projects

### 1. Real-Time Retail Feedback Intelligence
**Type:** MIT Capstone Project (Independent Build)
**Tech Stack:** Python, LLM API, Pandas, NLP, Google Colab

An end-to-end GenAI pipeline processing 19,000+ unstructured customer 
reviews in under 2 hours, converting raw text into structured business 
intelligence. Built and benchmarked Zero-Shot, Few-Shot, and 
Chain-of-Thought prompting strategies using an LLM-as-a-Judge framework. 
The classifier achieved 92% evaluation accuracy and 100% recall on 
critical complaints.

### 2. Amazon Product Recommendation Engine
**Type:** MIT Elective Project
**Tech Stack:** Python, Scikit-Surprise, Pandas, NumPy, Google Colab

Built and evaluated Rank-Based, Collaborative Filtering (User-User and 
Item-Item), and Matrix Factorisation (SVD) recommendation architectures 
on a multi-million-row product reviews dataset. Conducted grid-search 
hyperparameter tuning to minimise RMSE and MAE while preventing 
overfitting.

[View Project](Final_Recommendation_Systems_Learner_Notebook_Full_Code_upd.html)

### 3. FoodHub Delivery Performance Optimisation
**Type:** MIT Foundations Project
**Tech Stack:** Python, Pandas, NumPy, Matplotlib, Seaborn, Google Colab

Exploratory data analysis across 1,200 customers and 178 merchant nodes, 
modelling preparation velocity, transaction value, and transit time 
distributions to identify logistics bottlenecks. Multivariate 
visualisations segmented weekday vs. weekend consumer behaviour to 
produce evidence-based recommendations for fleet redistribution.
